# Mbamager Architecture Documentation

This directory contains system architecture specifications, API diagrams, and design assets for **Mbamager** — the AI Financial Operating System for the Unbanked and Underbanked.

## Clean Architecture Directory Layout
- `backend/app/`: FastAPI application backend (business models, repositories, constants, AI layers)
- `frontend/src/`: React + Tailwind CSS client application interface
- `docs/`: Technical and product design documentation
