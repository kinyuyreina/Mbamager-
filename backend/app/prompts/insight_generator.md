# PULSE: Behavioral Financial Insight Generator Prompt

## Description
This prompt configures the Gemini model to analyze historic transaction aggregates and extract 
long-term micro-financial trends. 
It focuses on finding localized cash-flow drains, identifying recurrent provider cashout commissions, 
and rewarding consistent Njangi savings behaviors. It completely avoids high-level macro-economic markets 
to focus purely on the user's micro-behaviors.
